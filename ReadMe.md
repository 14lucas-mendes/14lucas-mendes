## 👋 Sobre mim

Sou **Lucas Mendes**, desenvolvedor Front-End no Brasil, atualmente expandindo meus conhecimentos para **desenvolvimento Full Stack e ferramentas com Inteligência Artificial**.

Minha trajetória começou com HTML, CSS e JavaScript, evoluiu para **React, TypeScript e Next.js**, e agora avança também para desenvolvimento backend com **Node.js, bancos de dados, Python e agentes de IA**.

Antes da área de tecnologia, trabalhei com **manutenção ferroviária na CPTM**, um ambiente onde precisão, documentação, resolução de problemas e confiabilidade são essenciais. Levo essa mesma mentalidade para o desenvolvimento de software.

Hoje, meu foco é transformar o que estudo em projetos reais, indo além de apenas acompanhar cursos e tutoriais.

## 🎓 AI Tutor

### Uma Agent Skill de IA criada para aprendizagem contínua

O AI Tutor é um projeto focado em transformar agentes de IA em tutores de estudo mais estruturados.

Em vez de apenas responder perguntas, a proposta é ajudar o usuário a **planejar os estudos, praticar, revisar conteúdos esquecidos e acompanhar sua evolução ao longo do tempo**.

A skill foi projetada para funcionar em diferentes ambientes de agentes e assistentes de programação.

**Compatível com**

`OpenAI Codex` · `Claude Code` · `Cursor` · `OpenCode`

**O que estou explorando neste projeto**

- Agentes de IA
- Agent Skills
- Fluxos de aprendizagem persistentes
- Instruções estruturadas para agentes
- Ferramentas com Python
- Integração entre pessoas e IA no processo de aprendizagem

# 🧠 O que estou estudando agora

Meu foco atual vai além de simplesmente adicionar novas tecnologias à minha lista.

Quero entender como diferentes partes do desenvolvimento de software se conectam:

```txt
Front-End
   ↓
APIs e Back-End
   ↓
Bancos de Dados
   ↓
Automação
   ↓
Agentes de IA
   ↓
Produtos completos
```

Atualmente estou explorando:

- 🐍 Fundamentos e ferramentas com Python
- ⚙️ Arquitetura backend
- 🗄️ Bancos de dados relacionais
- 🤖 Agentes de IA e Agent Skills
- 🔄 Fluxos de automação
- 🧩 Construção de produtos completos, da interface à infraestrutura
